# יומן שטח — יישום GIS לאיסוף נתונים בשטח 📍

יישום ווב לטלפון נייד (PWA, עברית RTL): דוקרים נקודה במפה ומזינים לה
**שם מיקום · שם המזין · הערות · מספר תמונות**.

- **צפייה** בנקודות, בתמונות, ברשימה ובייצוא — פתוחה לכולם, **ללא הרשמה**.
- **דקירה והזנה** — רק למזין **מזוהה**: שם פרטי, שם משפחה ומספר נייד, מאומת בקוד חד-פעמי שנשלח ב-SMS. עריכה ומחיקה — רק למי שהזין את הנקודה.

## המנועים שעליהם היישום בנוי
| רכיב | מקור |
|---|---|
| הזדהות בנייד + קוד SMS (OTP), מסד נתונים, אחסון תמונות, הרשאות RLS | **Supabase** — אותו מנוע ואותו פרויקט של יישום ניווט השטח (`field-nav-app`) |
| שכבות מפה: רחובות, שבילי ישראל (Israel Hiking Map), טופוגרפית, צילום אוויר, Hillshade | `field-nav-app` + TSRS |
| Leaflet 1.9 | TSRS (flood-risk-assesment-police) |
| שפת עיצוב Luxury (נייבי · סגול · זהב שמפניה), Heebo, Material Symbols | פורטל הלקוחות של המרכז למיפוי ישראל (`mapi-customer-portal-poc`) |
| Service Worker: טעינה גם בקליטה חלשה, אריחי מפה שנצפו זמינים גם ללא קליטה | `field-nav-app` |

## יכולות
- דקירה בהקשה על המפה, או **"המיקום שלי" (GPS)** עם רמת דיוק; גרירת הסמן לדיוק המיקום.
- צירוף עד 10 תמונות לנקודה — **צילום ישיר מהמצלמה** או מהגלריה; התמונות מוקטנות במכשיר (1600px, JPEG) לפני ההעלאה.
- שם המזין ממולא אוטומטית משם המשתמש הרשום (ניתן לשינוי).
- גיליון פרטי נקודה: תמונות במסך מלא (החלקה בין תמונות), העתקת קואורדינטות, ניווט ב-Google Maps / Waze, שיתוף קישור ישיר (`?p=<id>`).
- רשימת נקודות עם חיפוש וסינון "שלי בלבד"; **ייצוא GeoJSON / CSV** (לפתיחה ב-QGIS / Excel).
- עדכון בזמן אמת — נקודה שהוזנה ע"י אחד מופיעה אצל כל הצופים.
- התקנה למסך הבית (PWA).

## שדות נקודה
שם מיקום · שם מזין · **סוג אתר · סטטוס הפרויקט · שיוך למערך · איש/אשת קשר במנהלת תקומה** · הערות · עד 10 תמונות.
ארבעת השדות הנוספים הם טקסט חופשי עם **השלמה אוטומטית**: הצעות מרשימה מנוהלת (טבלת `field_options`
ב-Supabase — עריכה דרך Table Editor) ומערכים שכבר הוזנו בנקודות קיימות. הגדרת השדות: `js/config.js` → `EXTRA_FIELDS`.

## מיתוג — לוגו מנהלת תקומה
הניחו את קובץ הלוגו הרשמי בנתיב **`field-collect/assets/tkuma-logo.png`** (PNG ברקע שקוף, רוחב ~600px).
היישום מזהה אותו אוטומטית ומציג אותו בכותרת ובמסך הפתיחה; כל עוד הקובץ חסר מוצג סמליל חלופי.

## שכבות מפה (`js/config.js` → `LAYERS`)
| שכבה | סוג | מצב |
|---|---|---|
| OpenStreetMap | רקע | פעילה |
| אורתופוטו — המרכז למיפוי ישראל | רקע | ממתינה לכתובת שירות; עד אז צילום אוויר חלופי (Esri), מסומן בבירור |
| מבנים — המרכז למיפוי ישראל | שכבת-על (WMS) | ממתינה לכתובת שירות |

כדי לחבר את שירותי מפ"י ממלאים `url` (ו-`layers` עבור WMS) בשכבה המתאימה. שירותי GovMap הרשמיים
דורשים מפתח (token) המונפק לדומיין של היישום — https://api.govmap.gov.il

## הקמה (פעם אחת, ~2 דקות)
1. Supabase Dashboard → **SQL Editor** → הדביקו את [`supabase/field_points.sql`](supabase/field_points.sql) → **Run**.
   הסקריפט יוצר את הטבלה `field_points`, מדיניות RLS, bucket תמונות ציבורי `field-photos` והפעלת realtime.
2. **הזדהות בסמס** — Authentication → Sign In / Providers → **Phone** → Enable, ובחירת ספק SMS
   (Twilio / MessageBird / Vonage / Textlocal) עם פרטי החשבון שלו. ללא ספק SMS לא יישלחו קודים.
   מומלץ: OTP expiry = 300 שניות, אורך קוד 6.
3. אם רוצים פרויקט Supabase אחר — עדכנו את `js/config.js`.

> כל עוד הטבלה לא נוצרה (או שאין חיבור לשרת), היישום עובר אוטומטית ל**מצב הדגמה**:
> הכל עובד, אבל הנתונים והמשתמשים נשמרים במכשיר בלבד. ניתן לכפות מצב זה עם `?demo`.

## הרצה מקומית
```bash
cd field-collect
python -m http.server 5090     # http://localhost:5090
```
GPS ומצלמה בטלפון דורשים HTTPS (או localhost).
